## Description

Author the top-down backbone **umbrella** ADR for the feature-gating posture: outbound/heavyweight
features ship **off** (opt-in, require explicit wiring); operational-hygiene jobs ship **on** (opt-out,
keep the database bounded). One rule — set the default against the danger in each direction. Names the
posture that the published 0004/0019/0040 (off) + 0046 (on) are instances of; cross-links them.
