# DOC-497 — facets + My Objects now ride the shareable `/search` URL (#1825 ST-1b / CTRIB-049)

ST-1b (the facet half of ST-1) puts the **8 facets + the result-class tabs + My Objects** into the URL,
layered on ST-1a's `?q=`. A **faceted** search is now shareable, bookmarkable, and back/forward-correct. This
completes the "facets are not yet in the URL" scope note ST-1a's DOC-495 left in `data-discovery/search.md`.

**Routing (G-C11):** unreleased behaviour (1.0.0). Authored + committed on the `release/1.0.0`-based branch
`docs/CTRIB-049-search-url-facets` @ `7259606`. The push to the shared train is the maintainer's action (see
`routing:`). It publishes when the train merges to documentation `main` at the 1.0.0 release gate.

## What was authored (on docs/CTRIB-049-search-url-facets @ 7259606)

In the **"The search URL is a shareable, bookmarkable `/search?q=` link"** section, replaced the bullet
**"Facet selections are not yet in the URL"** → **"Your filters are in the URL too"**: the sidebar facets, the
result-class tabs (incl. **My Objects**), and the query all live in the URL, so a shared/bookmarked link
reproduces the **entire faceted search**; selecting/clearing a filter (or the **All** tab) updates the address
bar; and back/forward step through filter changes as well as queries.
