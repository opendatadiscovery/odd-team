  - **Evidence**:
    - The aspect's purpose is to intercept methods annotated with `@ActivityLog`, capture BEFORE/AFTER state via the matching `ActivityHandler`, and emit an `ActivityCreateEvent` (`ActivityAspect.java:14-15` imports + aspect body). With `@Profile("!integration-test")` at line 24, the entire aspect is excluded from the Spring context when the `integration-test` profile is active.
    - The `DataEntityServiceTest.upsertMetadataFieldValueTest` (the only metadata-write test in the suite, `DataEntityServiceTest.java:164-191`) is a MOCKED unit test, not an integration-test against the `@ActivityLog` AOP; it would not detect the missing annotation even if the aspect were enabled.
    - `DataEntityDomainsTest.testDomainsInfo` (`DataEntityDomainsTest.java:36-93`) DOES run as an integration test (per `@SpringBootTest`-class context) — but with `@Profile("!integration-test")` on `ActivityAspect`, no activity event would fire even if a developer added `@ActivityLog` to `addDataEntityToDEG` / `deleteDataEntityFromDEG`. A unit test asserting "this method DOES emit `DATA_ENTITY_RELATION_UPDATED` to the activity-feed table" CANNOT run against the integration-test profile.
    - The pattern is therefore: developers adding `@ActivityLog` annotations can write integration tests that assert behavioural correctness but CANNOT assert audit-event emission in the same test; conversely, the absence of an `@ActivityLog` annotation (the audit-coverage gap) is invisible to integration tests by design.
    - The findings DOC-GAP-001 (strengthen — TERM_ASSIGNMENT_UPDATED fires on no-op deletes), DOC-GAP-153 (DEG-membership audit-absence + activity-feed page MISREPRESENTS coverage), DOC-GAP-156 (metadata upsert audit-absence — see), and DOC-GAP-158 (silent-200-on-missing UI-toast amplification) are all primary instances of the meta — the @Profile carve-out explains how each of these survived to production with build green.

DOC-GAP-137 is the front-end's zero-test-files state; DOC-GAP-155 is the back-end's deliberately-excluded-aspect state. Together they map two of the platform's four major absences in regression coverage (UI, audit, performance, security).
