## Description

Promote `ADR-CANDIDATE-044`: the notification replication slot + publication are exists-checked
and created on first leader run if absent, and never dropped by the platform — operator owns
cleanup (idempotent boot; never deletes an operator's objects). 📌 Consequences: bounded growth
requires operator intervention; the existing operator caveat is cross-linked, not duplicated.
