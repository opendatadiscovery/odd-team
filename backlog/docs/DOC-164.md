MVP scaffold is accepted when:

- [ ] **Extractor scaffolding shipped** (`lineage/_extractor/`): Python driver using `py-tree-sitter` + 4 grammars (TS, Java, Python, YAML); entry point supports `incremental` (default), `--full`, `--dry-run`, `--ref <branch>` modes; manifest read/write; JSONL nodes + edges read/write.

- [ ] **Second axis implemented** (`controllers`): tree-sitter queries for `@RestController` + `@RequestMapping` methods; produces `kind: controller | controller-method` nodes.
- [ ] **Third axis implemented** (`config_prefixes`): YAML walk of `application.yml` joined to Java `@ConfigurationProperties` consumer classes; produces `kind: config-properties-class | config-key-consumer` nodes.
- [ ] **Fourth axis implemented** (`ui_routes`): existing routes enumeration ported to lineage; produces `kind: route` nodes.
- [ ] **Fifth axis implemented** (`openapi_tags`): OpenAPI generator introspection; produces `kind: openapi-tag` nodes mapped to controller-method nodes via `exposes` edges.
