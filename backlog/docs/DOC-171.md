## Description

The ODD Platform UI ships with six locales (`en`, `es`, `ch`, `fr`, `ua`, `hy`) bootstrapped at `odd-platform-ui/src/locales/i18n.ts:1-33` with translation tables at `odd-platform-ui/src/locales/translations/{en,es,ch,fr,ua,hy}.json` and a `SelectLanguage` widget mounted on the toolbar at `odd-platform-ui/src/components/shared/elements/AppToolbar/SelectLanguage/SelectLanguage.tsx:28-33`. Live doc-site WebFetched 2026-05-27: zero mention of i18n / locale / multilingual / Spanish / French / Chinese / Ukrainian / Armenian / gear-menu / localStorage anywhere on the published documentation.

This feature is discoverable only by accidentally clicking the gear icon on the toolbar. Contributors don't know how to add a 7th locale. Product managers can't claim "we support 6 languages" without operator verification. The 2026-05-08 axis-pass already logged this as F-047; the 2026-05-27 Mode B run extends it with 14 behavioural facets — most materially the **12+ missing-key drift** on top-level navigation tabs (`Data Quality`, `Data Modelling`, `Master Data` are MISSING from every non-English locale; users see untranslated English in the toolbar).

## Acceptance Criteria

- [ ] A new page exists at the chosen canonical home (`docs/multilingual-ui.md` proposed; implementer may relocate). The page covers:
  - **Supported locales**: en (English) / es (Spanish) / ch (Chinese) / fr (French) / ua (Ukrainian) / hy (Armenian) — citing the file list at `odd-platform-ui/src/locales/translations/`.
  - **How users switch**: gear-icon → SelectLanguage widget on the toolbar.
  - **Persistence**: `lng = localStorage.getItem('i18nextLng') || 'en'` — the choice is browser-local (per-device, not per-user-account); explicit on the page so operators don't expect server-side propagation.
  - **Known caveat — missing translations**: at commit time, several keys (including `Data Quality`, `Data Modelling`, `Master Data`) are absent from every non-English locale and fall through to English. Frame as a community-fixable contribution invitation, not a defect.
  - **How to contribute a new locale**: add `odd-platform-ui/src/locales/translations/{code}.json`; add the `{code}` to the `lng`-detection allow-list + the `SelectLanguage` widget options + `i18n.ts` resources block. Cross-link to the build-and-run developer guide if applicable.
