## Description

`catalog-overview.md` was last touched before DOC-263 created `entity-detail-page.md` (batch-11). Three places on the page need to be updated to align with the new canonical page:

**Line 54 — Recommended-tile destination is factually wrong.** Current wording:

> Each tile carries a freshness indicator — an orange "time" icon signals stale entities ... and a per-class icon on the right indicates the entity type. **Clicking a tile opens that entity's Structure page.**

Verify against the codebase: clicking a Recommended-panel tile navigates to the entity's detail page (defaulting to the Overview tab), NOT to the Structure tab. The route shape is `/dataentities/{id}/overview` (the same destination as Search → result row, Directory → entity row, Activity feed → entity link). The "Structure page" wording is misleading — operators reading this expect to land on the schema/Structure surface, then are surprised by the Overview tab landing.

**Lines 64-68 — 'Catalog Overview vs entity Overview tab' admonition doesn't link to entity-detail-page.md.** Current wording:

> {% hint style="info" %}
> **Two distinct things share the name "Overview".** The **Catalog Overview** described on this page is the catalog's home page ... The per-entity **Overview tab** is the landing tab inside any data entity's detail page — entity description, owners, tags, terms, custom metadata. They are different surfaces; do not confuse them when reading docs or filing bug reports.
> {% endhint %}

The "per-entity Overview tab" phrase should link to entity-detail-page.md (the new canonical page that describes the per-entity Overview tab in full detail). Without the link the admonition is right-but-orphan — readers who want to understand the Overview tab's composition can't reach the canonical page from here.

**Lines 70-78 — 'Where to next' is missing entity-detail-page.md.** Current Where-to-next:
- Search and Filtering
- Directory
- Manual Object Tagging
- Data Entity Groups & Domains
- Metadata stale
- User-owner association
- Data Discovery overview

The destination of every tile click — entity-detail-page.md — is missing. Operators following the page flow downstream don't see the natural next page (the destination of every Recommended-tile, every Directory-row, every Search-row).
