## Implementation Notes

- **Cost shape per ADR**: ~2-3 weeks for MVP scaffold. Stage by axis: ship `ui_shell` first (closes i18n-class probe), then `controllers` + `openapi_tags` (replaces existing scanner enumeration), then `config_prefixes`, then doc-linkage validator. Each axis is independently shippable.
- **Stack**: `py-tree-sitter` + `tree-sitter-{typescript,java,python,yaml}`. No SCIP. No Joern. Reject stack-graphs (archived 2025-09).
- **Storage**: JSONL (nodes, edges) + YAML (manifest) + Markdown (rollups). Two-tier diffability — JSONL for tools, rollups for human PR review.
- **Granularity**: file + symbol (mixed). Function-level deferred to Phase 3.
- **Symbol IDs**: SCIP-inspired human-readable strings: `{repo} {lang} {package} {kind}:{descriptor}` (greppable, not opaque).
- **Probe-driven acceptance**: not coverage %. See `lineage/PROBES.md` (copied from research artefacts).
- **DO NOT punt research-backed decisions**: the ADR's revision-2 table is the source of truth. If implementation reveals a contradiction, that's a new finding to surface — not a re-litigation.
