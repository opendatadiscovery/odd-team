## What

Four defects on the catalog-wide Data Quality Dashboard. Doc-side LSN-019 disclosure ships via DOC-203; code-side fixes are this PLT.

**Defect 1 — Out-of-enum status blanks the WHOLE dashboard (HIGH).** `DataQualityContent.tsx:47-48` — `palette.runStatus[status].color ?? palette.dataQualityDashboard.unknown`. `palette.runStatus` keyed by exactly the SIX DataEntityRunStatus values. Any other `status` string makes `palette.runStatus[status]` undefined; `.color` throws TypeError BEFORE the `??` evaluates. A backend enum addition blanks the dashboard with the build still green.

**Defect 2 — LSN-019 'test_results' counts TESTS by latest-run-status, NOT RUNS (HIGH).** Three layers agree on the wrong meaning: UI label, per-category total, OpenAPI op name, live docs verbatim "count of test runs broken down by status." SQL delivers per-TEST-by-latest-run via `DATA_ENTITY_TASK_LAST_RUN.task_oddrn` PRIMARY KEY (one row per test). A test failing 100 times shows "1 failed" not "100 failed."

**Defect 3 — Autocomplete stuck spinner on backend error (MEDIUM).** `MultipleFilterItemAutocomplete.tsx:91-104` — stale-closure useEffect sets `optionsLoading=true` unconditionally, only false in `isSuccess`; dep array omits `hookResult`. Backend error → spinner strands forever.

**Defect 4 — freesolo autocomplete accepts unresolvable typed value (LOW).** `MultipleFilterItemAutocomplete.tsx:48-55, :166` — `freeSolo`; typed string with no `.id`; chip APPEARS but backend ignores.

## Why it matters

Defect 1 is **catastrophic-on-trigger**: a future backend enum addition blanks the dashboard with no degradation. Defect 2 is **silent semantic misinformation** at the platform's flagship DQ landing — a compliance reviewer reading the wrong question gets a confidently-wrong answer. Defects 3+4 erode filter usability.

Severity HIGH: Defect 1 is complete-page-failure + Defect 2 misleads audits.

## Suggested fix

**Defect 1 — defensive lookup:**
```tsx
- color: palette.runStatus[status].color ?? palette.dataQualityDashboard.unknown,
+ color: palette.runStatus[status]?.color ?? palette.dataQualityDashboard.unknown,
// + ErrorBoundary around the dashboard
```

**Defect 2 — LSN-019 alignment (Option B recommended):**
- Option A — rename label/operation/spec/doc to "Test Results — Latest Run by Status." Honest, no schema change.
- **Option B** — add a SECOND aggregation surface delivering true per-run counts (requires schema-tier event log).
- Option C — explicit doc disclosure (already shipping as DOC-203). Stop-gap.

**Defects 3+4 — autocomplete cleanup:**
```tsx
useEffect(() => {
  setOptionsLoading(hookResult.isFetching);
  if (hookResult.isSuccess) setOptions(...);
  if (hookResult.isError) setOptions([]);
}, [searchText, autocompleteOpen, hookResult.isSuccess, hookResult.isFetching, hookResult.isError]);
// + disable freeSolo for id-bound filter dimensions
```
