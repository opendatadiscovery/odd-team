## Description

The live Query Examples page (the existing `documentation/docs/data-modelling/query-examples.md` if DOC-046 has unblocked, otherwise the page-to-be-created by DOC-046) lists the 7 `QUERY_EXAMPLE_*` permissions but does NOT describe the cross-controller permission grid split, the XSS surface, the 10-of-13 unscoped endpoints, or the no-Activity-Log audit silence. Four facets, one operator caveats section:

**Caveat 1 — Permission grid is split across three controllers (F-025a.1).** `SecurityConstants.java:112-113, 187-193, 312-317, 318-324` wires:
- `QUERY_EXAMPLE_CREATE`, `QUERY_EXAMPLE_UPDATE`, `QUERY_EXAMPLE_DELETE` → on QueryExampleController
- `QUERY_EXAMPLE_DATASET_CREATE`, `QUERY_EXAMPLE_DATASET_DELETE` → on DataEntityController
- `QUERY_EXAMPLE_TERM_CREATE`, `QUERY_EXAMPLE_TERM_DELETE` → on TermController

Operators configuring Query Example permissions in one place (e.g., a Policy editor scoped to QueryExampleController) miss four of seven gates — the Dataset-link and Term-link operations are wired on different controllers and require the operator to think about three separate Policy scopes for one feature.

**Caveat 2 — 10 of 13 endpoints unscoped (F-025a.2).** Only the three mutation endpoints (CREATE / UPDATE / DELETE) are RBAC-gated. All reads + the search-session endpoints (10 endpoints total) fall through to global `.authenticated()`. Any authenticated user can read every Query Example in the platform regardless of Policy. Multi-team deployments expecting team-scoped query example visibility get platform-wide visibility.

**Caveat 3 — XSS via `MDEditor.Markdown` without rehype-sanitize (F-025a.3).** Query Example `definition` and `query` fields are stored verbatim (`V0_0_84:5` declares `text NOT NULL`) and rendered through `@uiw/react-md-editor` at two UI sites (`QueryExampleDetailsOverview.tsx:19, 25`) with no rehype-sanitize plugin configured. Operator-mutable text → unsanitized Markdown → stored XSS surface.

**Caveat 4 — No `@ActivityLog` on any Query Example mutation (F-025a.4).** Query Example create/update/delete/link operations are INVISIBLE on the global Activity Feed AND the per-entity Activity tab. There is no audit trail for query example mutations.
