## Description

A mechanical sweep of every `.md` file under `docs/` shows **26 pages lack `description:` frontmatter** out of 104 total (25%). The distribution is not random — it concentrates in three structural clusters plus four root entry pages:

**Cluster 1 — enable-security/ subtree (15 files, 100% missing):**
- `enable-security/README.md` (parent)
- `admin-promotion.md`, `audit-trail-scope.md`
- `authentication/README.md` + `authentication/{disabled,ldap,login-form,oauth2-oidc,s2s}.md` (6 files)
- `authorization/README.md` + `authorization/{owners,permissions,policies,roles,user-owner-association}.md` (6 files)

**Cluster 2 — use-cases/ subtree (6 files, 100% missing):**
- `use-cases.md` (parent)
- `use-cases/{dc-data-compliance, de-deprecation, dq-visibility, service-presales, viz-preparation}.md`

**Cluster 3 — root entry pages (4 files):**
- `Architecture.md`, `Features.md`, `README.md`, `configuration-and-deployment/trylocally.md`

**Excluded (correctly missing):**
- `SUMMARY.md` — GitBook's navigation manifest, never rendered as a page
- `.gitbook/includes/auth-type-oauth2-oa....md` — ORPHANED GitBook include (zero `{% include %}` consumers, absent from SUMMARY); carried the DOC-036 Okta=google bug. DELETED 2026-06-08 per DOC-343 (the 'embedded into other pages' note was false).

**Why this matters:**
1. **GitBook page meta description (SEO)** — the description renders as the `<meta name="description">` tag on the page. Without it, Google indexes the first paragraph of the body, which may not be the canonical positioning.
2. **Card-tile previews on section landings** — GitBook renders the description as the tile subtitle when a parent page lists this page in a card grid. Without it, the tile is title-only.
3. **Hover tooltips on internal cross-links** — GitBook surfaces the description on hover. Without it, cross-links are bare.
4. **Cross-page consistency** — 78 of 104 pages have descriptions (75%). The missing 26 are the outliers; bringing them in line is a one-line-per-file fix that closes a systematic editorial gap.
