## Description

Promote `ADR-CANDIDATE-003`: the platform is **read-collaborative** — `SECURITY_RULES` gates only
mutations, and `GET` reads fall through the `authenticated()` catch-all, so any authenticated user
can read the whole catalog (entities, lineage, search, activity). Absorbs `ADR-CANDIDATE-015`
(`/my*` owner-scoped reads) as the opt-in exception. This is the record `ADR-0002` forward-references
for the read posture.
