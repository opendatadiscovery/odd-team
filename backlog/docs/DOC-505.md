# DOC-505 — `data-lineage.md` contradicts itself about "Upstream dependents"

## Why

A *dependent* depends on you — i.e. is **downstream**. `data-lineage.md` states the correct semantics in its
endpoint table (the entities the user's owned entities **depend on**) and then asserts the opposite two lines
later, claiming the UI labels "Upstream dependents" / "Downstream dependents" are accurate and mean "the
dependents on the user's stuff". That sentence is wrong for the upstream direction, and it is wrong about the
CURRENT release, so it is a released-truth correction rather than train work.

The page also records the OpenAPI summaries for `getMyObjectsWithUpstream` / `getMyObjectsWithDownstream` as
describing a shape they do not describe.

Counting the API path (`/my/upstream`) and `catalog-overview.md` ("Upstream **Dependencies**"), ODD publishes
**three** different name-sets for one concept. CTRIB-062 (#1842 ST-8) converges the *search + Recommended-panel*
surfaces on "Upstream/Downstream of my data" on the 1.0.0 train; this item covers the lineage page's
self-contradiction, which is wrong today independently of that.
