## Description

Author the top-down backbone ADR naming the platform's most load-bearing data decision: **ODDRN
is the universal entity identity** — every entity carries a stable Open Data Discovery Resource
Name, and the same ODDRN means the same entity across ingests, producers, and time. This is what
makes idempotent ingestion, cross-system lineage, and external alert routing possible. No
candidate exists for it (the adr-archaeologist sees one sidecar at a time and surfaces instances,
not the cross-cutting constraint), so it is authored from code evidence with `promoted_from: none`.
