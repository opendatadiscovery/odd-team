## Description

Live `/user-owner-association` line 11 (verbatim): "After logging in you will see modal dialog in the bottom of the main page."

Code reality (verified `Overview.tsx:53-58` this session): the OwnerAssociation widget is rendered as the LAST child of `Overview.tsx`'s `S.Container` — an inline section at the bottom of the Catalog Overview page, NOT a modal dialog. There is no overlay; there is no backdrop; there is no dismiss-and-stay-on-page affordance. The user sees the section as part of the page's vertical scroll.

Operator-visible consequence: a user expecting a modal looks for an overlay; they instead scroll to the bottom of the home page. Minor framing drift but factually incorrect.
