## Description

CTRIB-019 (PLT-160 / GHSA-vw2p-vf4x-g3q6) adds a server-side allow-list so a data-entity **link** attachment
URL must use the `http`/`https` scheme (a stored-XSS defense). Post-fix, `data-discovery/attachments.md:39` —
"To attach a link to a remotely-stored file **(or any URL)**" — is inaccurate: non-web schemes (`mailto:`,
`ftp:`, `javascript:`, `data:`, …) are now rejected with HTTP 400.

Revise the page so it states link attachments accept an **http/https** URL, and add a one-line note that other
schemes are rejected. This is a post-fix **accuracy** update (NOT a pre-fix caveat): it must publish **with** the
fix, never before.

## Routing & gating (release-train + advisory)

- **status: blocked** until BOTH (1) the CTRIB-019 fix ships in **0.28.0** AND (2) GHSA-vw2p-vf4x-g3q6 publishes.
