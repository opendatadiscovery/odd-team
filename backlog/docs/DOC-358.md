## Description

The Multilingual UI section of `Features.md` describes the locale switcher as a "gear-icon picker on the toolbar" in two places:

- Line 284: "...loaded at SPA bootstrap and switchable through a **gear-icon picker on the toolbar**."
- Line 286: "...the **gear-icon picker affordance**, the per-device-not-per-user persistence model..."

There is no gear icon. The locale switcher lives in the **user-account / profile dropdown** in the top-right of the toolbar. In `AppToolbar.tsx`, the user-account box (showing the username, with `onClick={handleProfileMenuOpen}`) renders a `DropdownIcon` — not a gear (AppToolbar.tsx:72-82). Clicking it opens `AppMenu` (line 87), which contains the `SelectLanguage` entry (line 97) alongside `Logout` (line 117). An operator who reads "gear-icon picker on the toolbar" hunts the toolbar for a settings-gear that does not exist and cannot find how to change the language.

This is stale residue from DOC-171. The canonical page `multilingual-ui.md` was already corrected under DOC-304 — it now reads "Users switch the active locale from the **user-account menu** in the top-right of the toolbar" (multilingual-ui.md:7, :26) — but these two `Features.md` cross-references were not swept at the same time, so the overview page now contradicts its own canonical detail page.
