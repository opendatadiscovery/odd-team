## Description

Promote `ADR-CANDIDATE-022`: activity view-modes (ALL/MY_OBJECTS/DOWNSTREAM/UPSTREAM) are one
`ActivityType` enum parameter dispatched server-side via `switch(type)`, NOT separate endpoints —
a deliberate divergence from `DataEntityController`'s separate `/my*` owner-scoped endpoints.
