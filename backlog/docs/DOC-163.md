## Description

After DOC-162 ships (5-axis scanner Method), re-run `/enumerate scanners/docs/coverage/undocumented-features.md` against `odd-platform` `origin/main` to:

1. Refresh the existing 4-axis enumeration (commit drift since 2026-04-21 / `279fe8ee`).
2. Generate the new `ui_shell` axis items: every `<AppToolbar>` widget directory; `locales/i18n.ts` + `locales/translations/*.json`; theme provider; error-page family; auth-flow UI (login form, OIDC entry, LDAP entry, S2S entry); any TS file imported by `index.tsx` not already in axes 1-3; any component mounted inside `<AppToolbar>` render.
3. Generate the new `config_prefixes` axis items: every top-level `application.yml` key → `@ConfigurationProperties` consumer class.
4. Cross-reference each new item against the documentation repo's SUMMARY.md to identify undocumented gaps.
5. Write findings to `findings/docs-coverage-undocumented-features/2026-05-NN.md` (use the date the scan executes).
6. Update `state/coverage/docs-coverage-undocumented-features.yaml` with the new items + bumped `*_repo_commit_at_enumeration` SHAs.
