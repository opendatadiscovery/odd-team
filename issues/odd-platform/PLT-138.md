## What

When the Dictionary tab's search-session create or restore fails - including the common case of an expired auth session - the page renders a **silent frozen empty page**: there is no `.catch` on the dispatch, no `.rejected` reducer in the slice, and no error boundary on the route. The user sees an empty Dictionary with no error, no retry, and no indication that anything went wrong (e.g. that they need to re-authenticate).

This is **distinct from PLT-059 Defect 4** (the `TermsForm.tsx` authoring-dialog silent failure) - same silent-rejection *class*, different component (the Term-search session bootstrap vs the term-create dialog). The reflection notes both could fold into one "Terms subsystem `.catch` hardening" epic with PLT-059, but the Dictionary-tab session-bootstrap locus is not currently covered.

## Evidence

From the F-024 reflection (`lineage/odd-platform/feature-reflections/detail/F-024.yaml`), hypothesis H-012:

```
TermSearch.tsx:37-41   (@ ede5d277)
  // session create/restore dispatch with no .catch

termSearch.slice.ts (extraReducers)   (@ ede5d277)
  // no getTermsSearch.rejected reducer -> failure leaves the page frozen-empty
```

(See also the closely-related H-008 stale-bookmark-after-TTL frozen page, pinned by P-361 - deferred as a sibling; both are the same missing-`.rejected`-reducer family on the Term-search slice.)

## Impact

A user whose auth expired (or who hits any transient session-bootstrap failure) on the Dictionary tab sees a blank page with no error and no path forward - they cannot tell whether the catalog is empty, broken, or that they need to log in again. The same missing-rejection-handling also produces the stale-bookmark 404 frozen page (H-008).

## Suggested fix

Per the reflection's `proposed_fix_anchor`: add `.catch` on the `TermSearch.tsx:37-41` dispatch and `.rejected` reducers in `termSearch.slice.ts` that surface an error / retry. Distinct locus from PLT-059 Defect 4 (`TermsForm.tsx:100-111`) - could be folded into one "Terms subsystem `.catch` hardening" epic with PLT-059.
