## Description

Live `/catalog-overview` line 15 lists "Two sections are conditional — Domains appears only when at least one DEG is flagged as a domain." Lines 25-27 describe Domains as conditional. Lines 36-37 describe the Directory band but do NOT mark it conditional — the prose reads as if Directory is unconditional.

Code reality (sidecar reference `Overview/Directory/Directory.tsx:12-27`): the Overview-side Directory band renders `null` when `data?.length === 0`. On a fresh deployment with no DataSources registered yet (the bootstrap state), the Directory band is invisible.

Operator-visible consequence: on a fresh deployment, operators cannot discover from the home page that a Directory feature exists. The "Where to next" list at the bottom of `catalog-overview.md` does link to the Directory, mitigating discoverability — but the page itself misleads readers about which bands they should expect.
