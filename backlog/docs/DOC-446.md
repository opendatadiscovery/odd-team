## Description

The CTRIB-006 fix PR for odd-platform#1752 changes Relationships-surface behaviour at
0.28.0; the published pages carry DOC-229's caveats describing the pre-fix behaviour, so
the train (`documentation@release/0.28.0`, commit `f61b9c2`) updates them:

- **Feature page** (`docs/data-modelling/relationships.md`): the Target-column and `?type=`
  danger caveats become **fixed-in-0.28.0** notes (kept for operators on ≤0.27.x); the RBAC
  caveat is now purely about access — its visibility half (deleted/excluded listed) is fixed
  and stated positively in the UI walkthrough, including the deliberate dataset-tab nuance
  (`exclude_from_search` stays visible there; deleted/hollow hidden); the `relationship_id`
  caveat gains the in-payload trap (`erd_relationship_id` / `graph_relationship_id` do not
  round-trip) now also stated in the OpenAPI spec; caveat-count intro re-counted.
- **API-reference page** (`docs/developer-guides/api-reference/relationships.md`): the
  list-endpoint hint reworded — visibility rules apply as of 0.28.0; the
  no-per-resource-permission half stands.
