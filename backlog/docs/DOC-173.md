## Description

Four UI feature areas in the ODD Platform (Data Quality Dashboard, OwnerAssociations, DEGLineage, DatasetStructure-compare) wrap their root in `<Provider>` from `jotai` with per-feature byte-identical shape (per `odd-platform-ui/src/components/DataQuality/DataQualityProvider.tsx:4-6` + `DataQualityStore.ts:11-22` + `App.tsx:39, 73`). Per-Provider atom state is destroyed on unmount → reset on next mount. Route change unmounts the feature root → next visit shows all-empty defaults. The rest of the SPA uses Redux Toolkit where feature slices persist for the SPA session. The asymmetry is invisible until an operator hits it.

Operator-visible: a DQ Dashboard user picks 3 namespaces + 2 owners + 1 tag → clicks an entity to drill in → clicks back → finds the filter row empty. The URL-search-param mitigation at `DataQualityFilters.tsx:46-54` provides PARTIAL reconstruction; some dimensions survive a navigation round-trip, others don't. There is no first-visit hint, tooltip, or doc-side caveat naming this behaviour.

DOC-GAP-254 covers `WithPermissionsProvider` is-context-not-gate for the Overview / catalog-overview surface; F-104 is the **orthogonal jotai paradigm split** — partial overlap, not a duplicate.
