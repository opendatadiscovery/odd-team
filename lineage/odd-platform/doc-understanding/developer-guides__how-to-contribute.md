GitHub organization — creating issues, forking a repository, branching
(`issue/<issue_num>`), opening a Pull Request against upstream `main`, the CI/review
expectation, and reaching maintainers via the community Slack
(<https://go.opendatadiscovery.org/slack>). It is a process / community page, not a
feature page: nothing it describes is enforced or implemented by an
