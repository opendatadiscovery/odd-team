## Description

The platform change for odd-platform#1751 (CTRIB-014) ships at **0.28.0**: the 84 keys each non-English catalog
trailed `en.json` by are translated into `es/ch/fr/ua/hy`, the separate `br` 8-key gap (incl. the Master Data
tab) is closed, and a strengthened key-parity test asserts every non-en catalog == en's key set. So all seven
catalogs (`en/es/ch/fr/ua/hy/br`) carry the same 505 keys in 0.28.0.

The `multilingual-ui.md` "Known caveat — missing translations fall through to English" section was written when
~70 keys were absent. It must be reframed to the 0.28.0 reality: the fallback **mechanism** (a missing key →
English label) remains by design, but as of 0.28.0 there are no known missing translations across the seven
shipped catalogs, the #1748 (3 tabs) + #1751 (84 keys + br) catch-ups are both done, and a UI-suite parity check
guards against silent drift.

The CTRIB-014 PR also closed the related **unwrapped-string class** (PLT-205): ~208 hardcoded UI strings across
98 files were wrapped in `t()` + translated, and a `no-literal-string` lint guard was added. The caveat now
notes both the catalog completion AND the unwrapped-string fix + the two guards (key-parity + lint).
