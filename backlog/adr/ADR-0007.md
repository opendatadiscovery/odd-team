## Description

Promote `ADR-CANDIDATE-007` (18-sidecar, wisdom-test PASS) into a published ADR.

The decision: every reactive endpoint exposes a uniform `Mono<ResponseEntity<T>>` return
type; the success path is `.map(ResponseEntity::ok)` (or
`.thenReturn(ResponseEntity.noContent().build())` for deletes / void results); there is no
per-controller exception translation — error mapping is handled uniformly upstream. The
pattern is universal across every controller-method inspected.
