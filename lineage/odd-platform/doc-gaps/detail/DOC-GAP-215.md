    1. **Doc-side PRIMARY — `documentation/docs/features/master-data-management/lookup-tables.md`**: add an "Operational characteristics" section with four subsections:
       - **Cascade-on-delete**: "Deleting a Lookup Table via `DELETE /api/referencedata/table/{lookup_table_id}` cascades: (a) search-entrypoint rows are removed; (b) column-definition rows are removed; (c) the `lookup_tables` catalog row is removed; (d) the physical Postgres table in `lookup_tables_schema` is dropped; (e) the parent DataEntity is unlinked.
