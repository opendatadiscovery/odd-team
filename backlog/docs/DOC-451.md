## Description

The platform fix for odd-platform#1657 (CTRIB-010, reframed to a clarity overhaul) ships at **0.28.0**.
The Activity feed now exposes **three** distinct filters instead of two ambiguous ones, each with an
inline `(i)` help popover, and every event row shows **both** actor names:
- **Owner** — owner of the affected asset (`ownerIds`).
- **Made by (owner)** — the actor's CURRENT owner via the mutable `user_owner_mapping` (`user_ids`,
  un-deprecated; re-association changes which past events match).
- **Made by (user)** — the actor's immutable external username (`usernames` -> `activity.created_by`);
  works for users with no owner association; fed by the new `GET /api/activity/users`.
- Row shows the username + the user's CURRENT owner, explicitly labelled ("alice - current owner: Team A").
- A new reusable info-`(i)` popover affordance (ADR-0076 / the `InformationHint` component).
