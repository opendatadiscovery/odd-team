## Description

Four SPA areas back their filter/cursor state with per-feature jotai stores scoped to the component mount lifetime, unlike the Redux-backed majority of the SPA that persists for the session. The operator-visible consequence (F-104/H-001, F-104/H-005): selections/filters reset on navigate-away, the URL is the only cushion (and only the Data Quality dashboard mirrors filters to the URL), and **no UI affordance warns the operator the selection will not persist** — the persistence model is non-discoverable from the screen.

This is the operator-facing half of the architectural decision documented as an ADR draft (ADR-0076 — per-feature jotai stores deliberately scoped to mount lifetime). This item is the user-facing caveat only.
