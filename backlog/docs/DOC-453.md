## Description

Paired documentation item for **CTRIB-011 / odd-platform#1767** — the Data Quality dashboard
filter labelled "Title" is being relabelled to **"Owner title"** (it binds `OWNERSHIP.TITLE_ID`,
the owner's role, not the dataset name). The relabel ships in **0.28.0**, so the doc update rides
the `release/0.28.0` train and publishes at the release gate (the live manual describes the latest
released version, which still shows "Title" until 0.28.0 ships — `adrs/drafts/release-train-doc-gating.md`).

`documentation/docs/data-quality/dashboard.md` already documented the filter as "Title" with a
disambiguation caveat — the relabel makes that page describe a label the UI no longer shows. The
train edit:

- `:60` filter-dimension list: **Title** -> **Owner title**.
- `:63` warning hint heading + body: "**'Title' is the ownership role…**" -> "**The 'Owner title'
  filter is the ownership role…**"; label references and the `Title = Steward` example updated to
  `Owner title = Steward`. The substantive guidance is kept (it's the role like `Steward`, not the
  dataset name; there is no dataset-name filter here — use Search).
- `:65` "Owner and Title combine…" -> "Owner and Owner title combine…".
