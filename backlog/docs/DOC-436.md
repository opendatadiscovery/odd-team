## Description

- Line 107 (gcs `parameters` row): links to `.../odd-collector-gcp#googlecloudstorage`.
- Lines 164 and 166 (gcs_delta `parameters` row + its Source line): both link to `.../odd-collector-gcp#googlecloudstoragedeltatables`.
- Line 205 (Known limitations) finally states: *"The repo's anchor `#googlecloudstoragedeltatables` has a typo in the markdown (`##` instead of `#`) — link from the README directly if anchors don't resolve."*

The reader-flow defect: an operator scanning for the `gcs_delta` parameter list clicks the line-164/166 anchor first, lands at the README top with no scroll-to (the anchor is dead because of the upstream `##` typo), and only discovers WHY 40 lines further down in a Known-limitations bullet they may never reach.
