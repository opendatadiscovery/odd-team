## Description

`developer-guides/build-and-run/build-and-run-odd-platform.md` line 33 lists the frontend toolchain prerequisites as:

> * [Node 18.16.0] and [pnpm 8.4.0] (consider using [nvm] for that)

Both pins are far below what the `odd-platform-ui` package actually requires, and following the documented versions **blocks the build outright**:

- `odd-platform-ui/.nvmrc` pins Node **`v24.13.0`**.
- `odd-platform-ui/package.json#engines` requires **`node": ">=24.8.0 <25.0.0"`** and **`pnpm": ">=9.12.3 <10"`**.

pnpm enforces the `engines` block: pnpm 8.4.0 is outside `>=9.12.3 <10`, and Node 18.16.0 is outside `>=24.8.0 <25`. A contributor who installs the documented versions hits an engines-check failure before they can install dependencies or build the UI. This is a "follow our setup steps off a cliff" defect — the first thing a new contributor does is install the toolchain we tell them to, and we tell them the wrong (build-breaking) one.
