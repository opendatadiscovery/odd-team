    1. **Doc-side primary — `configuration-and-deployment/enable-security/authorization/owners.md`**: add an "Owner update mechanics" sub-section (extending the DOC-GAP-075 cluster on missing Owner doc completeness): "**Updating an Owner via `PUT /api/owners/{owner_id}` is a full-replace of the Owner's role assignments — NOT a field-level merge.** The `roles` field on `OwnerFormData` is OpenAPI-optional, but **OMITTING `roles` is INTERPRETED as 'set roles to empty', not as 'don't touch'**. Operators using the platform's UI (Management → Owners tab) are unaffected — the UI always sends the current roles list.
