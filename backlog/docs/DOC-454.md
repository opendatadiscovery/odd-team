## Description

Paired documentation item for **CTRIB-012 / odd-platform#1751 (PR #1783)**. The multilingual-ui page
carries a known-caveat that ~70 code-referenced `t()` keys are absent from the catalogs and "render raw
English" (DOC-171 / PLT-215). CTRIB-012 (ships **0.28.0**):

- adds the 70 missing keys to `en.json` (so they render English + become translatable), AND
- fixes the `fallbackLng` leak (`fallbackLng: 'en'` — `br` no longer leaks Portuguese to non-`br` users).

So at 0.28.0 the caveat is stale on two counts: (1) the ~70 keys are no longer absent from `en.json`;
(2) the "renders raw English" framing was already **wrong** for the `br`-only keys — they rendered
**Portuguese** ("Buscar por nome") via the fallback chain (the regression CTRIB-012 fixes, root cause
`8b0155f7`). The page should also note the locale set is complete and a key-parity guard test now keeps
`en.json` complete.

**Routing:** rides the `release/0.28.0` train (unreleased behaviour); the live page is accurate for the
latest release (0.27.13) until 0.28.0 publishes. NOT docs `main`.
