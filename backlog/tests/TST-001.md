## Description

The Lookup Tables sidecar reports `tests_coverage_semantic.test_files: []` — zero test coverage on the entire feature (LookupTablesList + LookupTables shell). Combined with F-058a (the `scrollableTarget` DOM-id copy-paste bug that silently truncates the listing at 30 rows — closed by PLT-057), the platform shipped a critical-severity UI defect on pillar P-03's SOLE user-facing surface with no regression anchor in CI. The same shape as F-026's zero-test gap (the per-table mutation flow has no integration test); F-058 extends the gap to the LISTING surface.

This test item adds a React Testing Library + jsdom integration test that mounts `LookupTablesList` with 35 seeded rows; scrolls the container to the bottom; asserts the network mock observes a `page=2` fetch. Catches the F-058a regression class in one screen; minimal scope.
