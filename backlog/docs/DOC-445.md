## Description

`business-glossary.md` (train ref `origin/release/0.28.0`, § "The Dictionary tab") asserts:

> The search-session URL (the `/termsearch/{uuid}` path you see in the address bar after a
> query) is **session-shared** — sharing the URL with a colleague gives them the same session
> view, including any filters and pagination state, and lets them mutate the session by
> changing those filters.

Two problems, both created/resolved by odd-platform#1760 (CTRIB-005, ships in 0.28.0):

1. **The claim was false for ≤0.27.x.** Since the Dec-2023 #1551 router refactoring the SPA
   mounted `/termsearch/*` as a splat, so a colleague opening the shared URL never reached the
   session — the SPA silently created a fresh empty term-search and rewrote the URL. The claim
   becomes true only as of 0.28.0 (the fix restores `/termsearch/:termSearchId`). search.md's
   parallel claim got exactly this version anchor on the train (DOC-444 /
   documentation@1d43d6e); this page — the second surface of the same fix — was missed.
2. **The expired-state behaviour is absent.** As of 0.28.0 an evicted/dead `/termsearch/{uuid}`
   renders "This search has expired" + a one-click **Start new search** recovery (the same
   shared element as catalog search). The page says nothing about session eviction for term
   search at all (the `search_facets` housekeeping TTL applies to term-search sessions too).

Failure shape: **parallel surfaces with drift** — same fix, two documented surfaces, one
updated. Fix direction: mirror search.md's two session bullets in operator language —
version-anchor the session-shared sentence ("as of 0.28.0; earlier releases silently discarded
the pasted id and started a fresh empty session") and add the expired-state + TTL sentence.
Author on the `release/0.28.0` train (the live manual keeps describing 0.27.x until the
release gate — the live page's claim is wrong for 0.27.x the same way search.md's was; the
recorded routing judgment on CTRIB-005 applies: anchor on the train, no interim main hotfix
for the 11-day window).
