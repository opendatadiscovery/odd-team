## Description

Author the top-down backbone ADR naming ODD's defining ingestion-architecture choice: **one wire
contract (the ODD Specification) shared by two producer strategies** — pull collectors poll on a
schedule, push adapters emit on the source's cadence — with the platform processing every payload
identically after ingest. No candidate exists (the decision spans the platform + collectors +
push-adapters + the spec; the adr-archaeologist sees one platform sidecar at a time), so it is
authored from code evidence + the canonical Architecture.md with `promoted_from: none`.
