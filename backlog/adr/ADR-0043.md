## Description

Promote `ADR-CANDIDATE-043`: the WAL consumer runs on one single-thread executor and blocks on
a Postgres advisory lock, so only the lock-holding replica consumes — exactly-once cluster-wide,
no external coordinator (same Postgres-advisory-lock mechanism as ADR-0020).
