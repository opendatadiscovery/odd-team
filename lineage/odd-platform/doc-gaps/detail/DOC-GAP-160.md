    - **Attack shape**: an authenticated attacker (or anonymous under DISABLED) creates a search session via `POST /api/search`, then issues `GET /api/search/{id}/facet/OWNERS?size=10000` and retrieves every owner name + per-owner entity count. Repeat with `?facet/TAGS`, `?facet/GROUPS`, etc. The aggregate counts reveal catalog cardinality across every owner, every tag, every namespace, and every Data Entity Group. The attacker need not read any individual entity to enumerate the catalog's organisational shape.
  - **Proposed doc action**: **Two-part action**.
    1. **Doc-side primary**: extend `features/data-discovery/search.md` with a "Visibility model" admonition: "**Facet counts are computed catalog-wide.** The `My Objects` toggle in the UI scopes the search RESULT list to the entities you own; it does NOT scope the facet COUNTS. Selecting the Owner facet reveals every owner in the catalog and the count of entities each owns; selecting the Tag / Group / Namespace / Type / Status facets reveals the cardinality of every value of that facet. This is the platform's read-collaborative posture: ODD treats the catalog as community-readable. For multi-tenant deployments where catalog cardinality itself is sensitive (e.g. an Owner facet revealing competitor names + sizes), either gate `/api/search/{id}/facet/{type}` at the perimeter, deploy one ODD instance per tenant, or accept the disclosure as part of the catalog's discovery surface."
    2. **Code-side optional** (file `/log-issue odd-platform`): two ordered options. (a) **Minimum**: add an optional `OWNERSHIP.OWNER_ID = ?` predicate to every facet aggregator gated by a feature flag `search.facets.owner-scoped: false` (default off for backwards-compat); when enabled, facet counts respect the caller's owner. (b) **Full**: redesign the facet aggregators to take a principal-derived `Set<Long> visibleOwnerIds` and scope every count; pair with a `facet.cardinality-bucket-only: true` mode that returns log-scale counts (low/medium/high) instead of exact numbers for the most-sensitive facets.
