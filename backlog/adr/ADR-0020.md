## Description

Promote `ADR-CANDIDATE-020` into a published ADR: the post-message request returns 202 after
persisting; a background `DataCollaborationMessageSenderJob` delivers under a Postgres advisory
lock (single-leader, once-per-message cluster-wide) with a bounded per-message retry — no
message broker, only Postgres. Canonical home for the advisory-lock mechanism (ADR-0043 references it).
