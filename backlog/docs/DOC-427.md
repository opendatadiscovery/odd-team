## Description

The Business Glossary "Visibility and cross-tab UX" section says: *"An operator landing on a freshly-created term page with no links has no UI signal that linking is supported — **only the Query Examples tab is always visible.**"* The "only Query Examples" claim is **incorrect** — verified against the tab-visibility code, not merely soft-flagged. On a zero-link term, **two** tabs are always visible: **Overview** and **Query examples**.

`TermDetailsTabs.tsx` builds the tab array (`TermDetailsTabs.tsx:14-44`). Each tab's visibility is governed by a `hidden` property:
- **Overview** (`:17-19`) — no `hidden` property → always visible.
- **Linked entities** (`:21-25`) — `hidden: !termDetails?.entitiesUsingCount` → hidden when the count is zero/undefined.
- **Linked columns** (`:26-31`) — `hidden: !termDetails?.columnsUsingCount` → hidden when zero.
- **Linked terms** (`:32-37`) — `hidden: !termDetails?.linkedTermsUsingCount` → hidden when zero.
- **Query examples** (`:38-41`) — no `hidden` property → always visible.

So the doc's underlying point is sound — the three `Linked*` tabs gate on their counts and a zero-link term hides all three — but the "only Query Examples" phrasing drops the Overview tab, which is equally unconditional (and is in fact the default landing tab: `TermDetailsRoutes.tsx:46` redirects the bare path to `overview`). An operator reading the page might conclude the Overview tab itself is count-gated, which is wrong: the Overview (the About-style description, the canonical landing surface the same page describes at "A term's detail page shows the **Overview**…") is always present.

Note: the **Query examples** tab is shown unconditionally but its *content* is permission-wrapped — `TermDetailsRoutes.tsx:33-45` mounts `TermQueryExamples` inside a `WithPermissionsProvider` gated on `QUERY_EXAMPLE_TERM_CREATE` / `QUERY_EXAMPLE_TERM_DELETE`. That gates create/delete affordances, not tab visibility, so it does not change the "tab is always visible" fact; do not conflate the two when correcting the sentence.
