## Description

The Lookup Tables page's "Known operator caveats" section publishes a `{% hint style="warning" %}` describing the
**#1781 bug**: the Create/Edit Lookup Table Description was stored only on the lookup-table record and never reached
the catalog Data Entity, so the entity overview showed nothing (with an entity-About workaround).

odd-platform#1781 / CTRIB-032 (milestone 0.29.0) fixes this: a lookup table is treated as a **source** the platform
auto-ingests, so its description is propagated to the Data Entity's **external (source) description**, which the
overview renders; the entity's **internal** description (the term-linkable About editor) stays independent. Once
0.29.0 ships, the caveat is FALSE.

**Change (already authored on the `release/0.29.0` train @ 9e35fcb):** the warning caveat is replaced with an
`info` note — *"Where a Lookup Table's description appears"* — explaining the external (LT/source) vs internal
(catalog-curated, term-linkable) descriptions and that a future release may consolidate them. Publishes — with the
caveat gone — at the 0.29.0 release gate (release-train doc gating; the live manual describes the latest published
release until then).
