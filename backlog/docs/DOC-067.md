## Description

### Capture method

Used a Python + Playwright (chromium) headless script (`/tmp/odd_screenshot.py`, ephemeral) to:

1. Open `https://demo.oddp.io/` with the user-provided `SESSION` cookie (`SESSION=ab6a50ca-a0ed-4b08-b310-505ad93f2115`, scoped `domain=demo.oddp.io, path=/, secure, httpOnly`).
2. Wait for `networkidle` + 3s for the React SPA to render full content.
3. `full_page` PNG capture at 1600×1100 viewport.

Result page H1: "Data Catalog" (the Catalog Overview); 451 entities; 14 top-tags rendered; 8 datasource types in the Directory section; signed in as "Data Platform Engineer".

### Sections rendered (vs. doc-text expectation)

The original doc text on `Features.md` listed six sections (Main search → Top tags → Domains → Entities → Directory → Owner association). Today's UI renders Main search, Top tags, Entities, Directory, **Recommended** (a section the doc text did not mention), and conditionally Domains + Owner association. This commit extends the doc text to:

- Add **Recommended** with its operator-meaningful description (My Objects / Upstream / Downstream / Popular four-column layout).
- Mark **Domains** explicitly as conditional (renders only when at least one DEG is flagged as a domain).
- Mark **Owner association** explicitly as conditional (renders only when authentication is enabled and the signed-in user is not yet linked to an Owner).
