## What

Three of the main navigation tabs in the toolbar — **Data Quality**, **Data Modelling**, and **Master Data** — are passed through the `t()` translation function but have **no translation key in any locale file** (neither `en.json` nor `ua.json`). Because react-i18next falls back to the key itself when no entry exists, these three labels always render the raw English string, even when a user has switched the UI to Ukrainian. The other six toolbar tabs (Catalog, Directory, Management, Dictionary, Alerts, Activity) all have proper keys, so the navigation strip is partially-localised: six tabs translate, three are stuck in English.

## Where

`odd-platform-ui/src/components/shared/elements/AppToolbar/ToolbarTabs/ToolbarTabs.tsx:46,51,56` — the three labels go through `t()` but the keys are absent from the locale catalogs:

```tsx
name: t('Data Quality'),     // :46
...
name: t('Data Modelling'),   // :51
...
name: t('Master Data'),      // :56
```

Confirmed absent in both locale files (`odd-platform-ui/src/locales/translations/en.json` and `ua.json`): grepping each of the three literals returns **0** matches in both files, whereas every sibling tab label ("Catalog", "Directory", "Management", "Dictionary", "Alerts", "Activity") returns exactly **1** match in each. So three of the nine toolbar tabs have no key at all.

## Why it matters

Silent, partial-localisation defect on the platform's persistent primary navigation — the chrome every user lives in. A Ukrainian-locale user sees six tabs in Ukrainian and three in English, side by side, which reads as a half-finished translation and undercuts confidence in the localisation. It is also a latent trap for any future locale: adding a new language will not cover these three tabs because there is no key to translate. Medium because it is presentation-only (navigation still works), but it is on the most-visible surface and affects every non-English user.

## Suggested fix

Add `"Data Quality"`, `"Data Modelling"`, and `"Master Data"` keys to **every** locale file (`en.json` with the English value, `ua.json` with the Ukrainian translation), matching the pattern already used for the six working tab labels. No code change in `ToolbarTabs.tsx` is needed — the `t()` calls are already in place; only the catalog entries are missing.
