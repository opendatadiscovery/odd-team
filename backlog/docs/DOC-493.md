# DOC-493 — document the Favorites feature (#1815 / CTRIB-039 S4)

CTRIB-039 ships **Favorites** (#1815): a user stars any viewable asset — a data entity, a glossary term,
or a query example — and the starred set appears as a panel on the Catalog Overview home page and as a
top-level **Favorites** tab. The S3 review's DOC follow-up #2 required documenting **every** user-visible
favorites surface (the panel, the detail-header/search/list-row stars, the tab + filter, the "Asset"
umbrella term), which this item delivers.

**Routing (G-C11):** unreleased behaviour (1.0.0). **✅ AUTHORED on the `release/1.0.0` documentation train
@ `72e244d`** (2026-06-28) — the train already existed (DOC-492 @ `4d928eb`). It publishes when the train
merges to documentation `main` at the 1.0.0 release gate; the live manual is unchanged until 1.0.0 ships.

## What was authored (on release/1.0.0 @ 72e244d)

- **`data-discovery/favorites.md` (NEW)** — the feature page: starring an asset (detail headers + Search
  result rows + the Dictionary / Query-Example list rows), the home-page panel, the Favorites tab +
  Asset-type filter + rich rows, the star-vs-Popular icon distinction, per-user identity, and the
  `auth.type=DISABLED` shared-bucket caveat.
- **`data-discovery/catalog-overview.md`** — a `### Favorites` section (the always-on band, distinct from
  the owner-gated Recommended panel), placed between Directory and Recommended (the render order).
- **`main-concepts.md`** — the **Asset** umbrella term (Data Entities + Terms + Query Examples) in Terms &
  Aliases (favorites ADR D8), distinguished from the data-entity-only Search "Type" facet.
- **`SUMMARY.md`** — the Favorites page under Data Discovery, after Search.

## Follow-up at the Group-B slice (S5)

The cross-kind facets (namespace / datasource / tag / owner), the entity-class taxonomy refinement, and
full-text search over favorites are the API-contract slice (S5, still in progress). When S5 ships, extend
`favorites.md`'s "Favorites tab" section with the full facet set + FTS (the current page describes the
Asset-type filter shipped in S4). No rewrite expected — an additive extension.
