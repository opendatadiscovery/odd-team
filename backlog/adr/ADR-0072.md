## Description

Author the top-down backbone **umbrella** ADR for the platform's defining technology posture:
**contract-first, reactive, two-language stack** — Spring WebFlux + R2DBC backend, React/TS SPA, and
one OpenAPI document generating both the server interfaces and the browser client. Names the stack
that the already-published 0001/0007/0008 are facets of, and folds the reactive-TX boundary
(candidate 067) as a consequence; cross-links the instances rather than superseding them.

## Addendum (2026-06-02) — serialization-naming consequence added

Folded the **snake_case-wire / camelCase-client serialization-naming** convention into this ADR as a Consequence + Evidence bullet (maintainer-chosen 2026-06-02: extend ADR-0072, not a new ADR — it is a property of "one openapi.yaml → generated per-language clients", not its own backbone decision; wisdom test → consequence of an existing decision, fold don't mint).

What was added (descriptive, code-cited):
- Wire field names are the contract's, in `snake_case` by house convention (≈195 fields in `odd-platform-specification/components.yaml`); each generated client re-exposes them per-language — TS `*FromJSON` camelCases (`test_results`→`testResults`, e.g. `odd-platform-ui/src/generated-sources/models/DataQualityResults.ts`); Java binds via `@JsonProperty("snake_case")` (27 snake bindings, e.g. `access_token`/`entity_classes`/`external_name`). VERIFIED via grep + read.
- Anything reading the **raw wire** (test interception, proxy, `curl`) must use snake_case names.
- **8 camelCase exceptions** in the contract itself: `authType` (components.yaml:2498), `projectVersion` (:2496), `usedCount` (:314), `hasNext` (:1401), `maxSize` (:2413), `fileName` (:2421), `dataEntityId` (:1778), `dataEntityName` (:1776). A known inconsistency; un-normalisable without breaking every client → documented, not fixed. VERIFIED via read.

Provenance: surfaced authoring the Tier-1 UI-e2e specs — a Playwright route interceptor matched camelCase keys and silently no-op'd against the snake_case wire (a false green; fixed in `integration-tests/e2e/helpers/net.ts`, run-log `2026-06-02-known-bugs.md`).
