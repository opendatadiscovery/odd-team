## Description

The `docs/coverage/undocumented-features` scanner reported 100% coverage on 2026-04-21 (commit `279fe8ee`) while missing six undocumented i18n features. Root cause: the scanner's three enumeration axes (UI routes, REST controllers / OpenAPI tags, Management pages) are structurally blind to cross-cutting client-side capabilities — i18n bootstrap, theme provider, AppToolbar widgets, error pages, auth-flow UI, browser persistence, anything keyed off `application.yml` prefixes that don't map 1:1 to a controller.

This item ships the **cheap parallel patch** authorised in `adrs/drafts/code-lineage-substrate.md` Q2 (research-backed revision 2): add a `ui_shell` axis (cross-cutting UI capabilities) and a `config_prefixes` axis (`@ConfigurationProperties`-keyed YAML namespaces) to the scanner's Method section. Forward-compatible: the enumeration logic folds into the lineage substrate's `ui_shell` and `config_prefixes` axes verbatim if/when DOC-164 (substrate MVP scaffold) ships.

The patch is the scanner-definition change only; the actual re-enumeration against current platform `origin/main` and resulting findings are tracked separately under DOC-163.

## Acceptance Criteria
