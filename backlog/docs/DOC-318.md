## Description

Viewed as a SET, the ADR-to-ADR cross-link graph is navigable **top-down** (umbrella → instance) but not **bottom-up**: every umbrella/synthesis ADR (0071, 0072, 0075) and every late-authored ADR (0058, 0074) is linked *to* but adds no link *back* into the earlier instance pages. The editorial audit found **31 of 53** ADR-to-ADR edges are one-directional.

Representative (verbatim) — ADR-0004's entire See-also is `* [GenAI](../../active-platform-features/genai.md) — …` (zero ADR links) despite being the canonical disabled-by-default example referenced inbound by 0019, 0040, 0046, AND the 0075 umbrella.

**Failure shape:** non-bidirectional cross-link (aggregate pattern). The family graphs are navigable top-down but not bottom-up.

## LSN-009 scope note (grep-the-backlog-first — read before implementing)

The per-item reasoning is sound; this item is the one-pass sweep now that the set is complete.
