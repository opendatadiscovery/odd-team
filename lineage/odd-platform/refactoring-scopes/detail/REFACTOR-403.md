  - **Statement**: `CognitoLogoutSuccessHandler.java:43` builds `logout_uri` from `UriUtils.getBaseUri(requestUri)` (the inbound HTTP request's base URI). Per AWS docs (WebFetched 2026-05-19 status 200): "If the value of `logout_uri` is one of the **Allowed sign-out URLs** for your app client, Amazon Cognito redirects users to that URL" — otherwise Cognito returns an error page. An ODD deployment where the user reaches the platform via an alias hostname not registered in Cognito's app-client "Allowed sign-out URLs" sees a Cognito-side error page after clicking logout. The ODD live docs (WebFetched 2026-05-19 status 200) do not mention AWS Cognito's "Allowed sign-out URLs" app-client allowlist requirement. The coupling is implicit (the platform dynamically derives the URI; the operator MUST manually allowlist every external hostname in Cognito).
