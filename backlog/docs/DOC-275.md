## Description

`entity-detail-page.md` is the canonical composition reference for the data-entity detail page in the catalog. It enumerates the aspect-level deep dives that operators need to follow for per-panel detail. After the recent sweep shipped three NEW canonical-home pages (`entity-description.md` — DOC-187, `custom-metadata.md` — DOC-189, `per-column-annotation.md` — DOC-193), the entity-detail-page.md has not been updated to surface these three aspect pages. Three distinct locations on the page omit them:

**Location 1 — intro paragraph aspect-page enumeration (line 9):**

> *"For the aspect-level deep dives — applying [tags](tagging.md), curating [business names](business-names.md), wiring [statuses](statuses.md), attaching [files](attachments.md), reading the [stale indicator](metadata-stale.md), and grouping into [Data Entity Groups](groups-domains.md) — follow the per-aspect pages cross-linked below."*

Missing: `entity-description.md`, `custom-metadata.md`, `per-column-annotation.md`. The phrase "aspect-level deep dives" implies completeness; an operator reading this intro and going off to the named aspect pages will not discover the three NEW aspect pages.

**Location 2 — "Where to next" enumeration (line 136):**

> *"[Manual Object Tagging](tagging.md), [Business names](business-names.md), [Data Entity Statuses](statuses.md), [Data Entity Groups & Domains](groups-domains.md), [Data Entity Attachments](attachments.md), [Metadata stale](metadata-stale.md) — per-aspect deep dives for the panels and header affordances on this page."*

Same three omissions. The terminal cross-link section on the canonical composition page does not surface the three new aspect pages at all.

**Location 3 — panel-matrix Description row cross-link (line 23):**

> *"| Description | Main | The entity's human-readable description, with linked terms inline. | [Business Glossary](../data-glossary/business-glossary.md) for the term-link surface. |"*

The cross-link points at `business-glossary.md` (which covers terms / glossary) rather than at `entity-description.md` (which is the canonical home for the Description panel itself — Markdown surface, render pipeline, XSS-class admonition). The business-glossary link is correct for the term-link half but should not be the sole aspect-page link for the Description row.

**Location 4 — per-column-annotation invisible:**

The page references the **Structure** tab (line 37, line 45) but never links `per-column-annotation.md` — the canonical reference for the per-column composer (description / tags / glossary terms / enum values / business name). An operator navigating from the entity-detail-page composition reference cannot find the Structure-tab column-composer documentation through this page.
