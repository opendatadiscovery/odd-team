## Description

Promote `ADR-CANDIDATE-046`: housekeeping ships `enabled: true` verbatim, gated by a strict
`@ConditionalOnProperty(havingValue="true")` (no `matchIfMissing`) — opt-OUT semantics; a default
deployment deletes aged data. A deliberate divergence from the ship-disabled-by-default family
(ADR-0004/0019/0040): bounded DB growth is the platform's default operational posture.

## Acceptance Criteria

- [ ] Published page exists, five sections, descriptive voice.
- [ ] Evidence cites re-verified `file:line` (Gate A2): the verbatim default, the strict condition, the test-profile opt-out.
- [ ] 📌 Consequences state the delete-by-default posture descriptively (no exploit / internal gap-ID).
- [ ] Ontology frontmatter (Gate A4); `description ≤200`. Index + SUMMARY same commit (Gate 7). Gate 11 clean. Live-site post-merge (Gate 8).
