## Description

The FE unit suite's `i18n-key-parity.test.ts` guard (wave 3 — "no unwrapped object-property label
literal", odd-platform#1751 / PLT-205) is **RED on odd-platform `main`** (verified at `66c472e2`), and
has been since **#1798 (CTRIB-028, `fd71eb3d`, 2026-06-22)** introduced the offending line.

- **Offender:** `LinkedTermsList.tsx:63`
  `message: error instanceof Error ? error.message : 'Unknown Error',`
  The guard's `OBJ_PROP_LITERAL` regex matches `message: '...'` and `isUserFacingPhrase('Unknown
  Error')` returns true (uppercase-initial, has lowercase, not all-caps, not PascalCase), so it is
  flagged as an "unwrapped user-facing label literal."
- **It is arguably a false positive:** the literal is the fallback of an `Error.message` ternary used to
  build an error-like object (not a rendered tab/menu/status label), and `t()` is not in scope there.
- **Measured:** `vitest run` on the working tree (node 24 via `node:24-slim`) = **1 failed / 75 passed**
  (18 files, 17 passed); the single failure is exactly this offender. Byte-identical on `origin/main`
  (`git show origin/main:…/LinkedTermsList.tsx` line 63 == worktree) and in a file CTRIB-039 never
  touched → **pre-existing, not a favorites regression.**

This means odd-platform's FE vitest suite has been red on `main` since 2026-06-22 — either the FE
vitest is not a blocking CI gate, or the breakage slipped #1798's review. Worth surfacing upstream.

## Acceptance Criteria
- [ ] Decide the fix shape: (a) refactor the `LinkedTermsList` error-object so the fallback is not a
  bare label literal (e.g. a non-flagged constant / a non-label property name), OR (b) refine the
  guard's `isUserFacingPhrase` / `OBJ_PROP_LITERAL` to exclude error-construction objects
  (`message:` inside an `error instanceof Error ? … : '…'` ternary). Prefer the guard refinement only
  if (a) would weaken a real check.
- [ ] `vitest run src/locales/__tests__/i18n-key-parity.test.ts` GREEN on a clean `main` checkout.
- [ ] No real i18n offender is masked (the guard still catches genuine unwrapped UI labels).
