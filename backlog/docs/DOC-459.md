## Description

The platform change for odd-platform#1750 (CTRIB-015) ships at **0.28.0**: the Test-reports **Severity**
control no longer saves instantly on selection. It now conforms to the entity-Status edit pattern — choosing a
severity opens a confirmation dialog ("Change the severity from X to Y?") and the change is persisted only on
confirm; the panel always renders the test's stored severity (the fix also removes the prior sibling-test render
bleed). See `adrs/drafts/confirm-and-store-reduce-field-edits.md`.

`docs/data-quality/sla-statuses.md` "Setting severities" step 2 described the affordance as a plain "choose a
severity — Minor, Major, or Critical", which is now incomplete (it omits the confirm step). The refinement adds
"— then confirm the change in the dialog that appears. The severity is only saved once you confirm; the panel
always shows the test's stored severity until then." The page's existing audit-silence caveat (severity changes
are not logged in the Activity Feed) remains accurate — this PR does **not** add audit logging (explicitly out of
scope; still tracked by IT-057 CORNER 2).
