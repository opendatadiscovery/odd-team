## What

The global Alerts page tab labelled **"All"** shows only **OPEN** alerts. `ReactiveAlertRepositoryImpl.listAllWithStatusOpen` hard-filters `ALERT.STATUS = OPEN`, and the sibling My Objects and Dependents queries carry the identical hard-coded `STATUS=OPEN` filter — so `RESOLVED` and `RESOLVED_AUTOMATICALLY` alerts never appear on **any** of the three global tabs. The data is not gone (a single entity's Alerts tab uses `getAlertsByDataEntityId`, which has no status filter), but the global page cannot surface it: there is no `status` query parameter on `getAllAlerts` / `getAssociatedUserAlerts` / `getDependentEntitiesAlerts`, and `ALERT.STATUS` is an available-but-unused column on the list API. This is the same Category-B name-vs-behaviour class as LSN-019 (`TagController.listMostPopular`).

This is **distinct from PLT-050** (the Alerts UX cluster: hardcoded size-30, no filter UI, no bulk-resolve, default-tab redirect, hidden-but-navigable tabs), which does not cover the "All"-label name-drift or the missing status filter. The DOC side is already corrected (the live alerting page documents the OPEN-only behaviour; DOC-291 done). The code-side relabel / status-param remains.

## Impact

A steward searching the global Alerts page for an alert they resolved an hour ago cannot find it and reasonably concludes it was purged — potentially re-investigating the underlying issue or filing a "lost alerts" support ticket. The only way to view a resolved alert is to navigate to the specific entity's Alerts tab (if they know which entity). The UI label "All" actively misrepresents the population it shows.

## Suggested fix

Per the reflection's `proposed_fix_anchor`: add an optional `status` query param on `getAllAlerts` / `getAssociatedUserAlerts` / `getDependentEntitiesAlerts` (`AlertController.java:36-57`) and plumb it to `ReactiveAlertRepositoryImpl.listAllWithStatusOpen` (drop the hard-coded `eq(OPEN)`, default to OPEN); **or** relabel the tab from "All" to "Open" to match the behaviour. DOC side already corrected (DOC-291).
