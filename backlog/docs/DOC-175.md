## Description

The Metadata Stale page (`data-discovery/metadata-stale.md`) shipped with DOC-157 and currently covers the indicator's meaning, the surfacing surfaces (10 UI consumers), the 7-day default, and common cause categories. It does NOT cover five behavioural caveats that the Mode B substrate F-146 surfaced as operator-relevant:

1. **Silent-disable when `odd.data-entity-stale-period` is removed.** `DataEntityStaleDetector.java:10-17` reads `@Value("${odd.data-entity-stale-period}")` with no `:7` annotation fallback (the 7-day default lives in `application.yml:211`, not in the annotation). If an operator removes the key from their override YAML, the predicate is null-guarded and silently returns "not stale" for everything — no admin signal, no page banner, no log warning. The orange clock simply stops appearing.
2. **Never-ingested entities report `is_stale=false`.** A manually-created entity that has never been ingested has `lastIngestedAt=null` and the predicate returns false. The stale indicator is silent on entities that, arguably, are the most stale of all.
3. **Ingestion-write can forge freshness.** Any caller able to POST `/ingestion/entities` can update `lastIngestedAt`. Under `auth.ingestion.filter.enabled=false` (default — see DOC-168), an unauthenticated network-reachable caller can keep the stale clock from appearing.
4. **Clock-skew flicker on horizontally-scaled deployments.** The predicate compares `lastIngestedAt + 7 days` against `now()` on the rendering node. Different nodes with skewed clocks render the indicator inconsistently per render.
5. **Deployment-wide threshold, no per-tenant / per-namespace / per-datasource window.** A 7-day window is sensible for the OLTP-ish datasources but punishing for monthly-cadence warehouse extracts.

Plus an IA-side gap: no glossary entry + no first-time-hover legend for the orange-clock icon. The page is reachable from `main-concepts.md` (per DOC-157's added back-links) but discoverability is poor for a first-time operator landing on a search-result row.
