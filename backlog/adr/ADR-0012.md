## Description

Promote `ADR-CANDIDATE-012` into a published ADR. The decision: the attachment storage
backend is selected at **boot time** via `@ConditionalOnProperty` on `attachment.storage`;
switching modes requires a Platform restart, with `LOCAL` as the **implicit default** via
`matchIfMissing=true`. The wiring is a boot-time bean decision, not a runtime switch.
