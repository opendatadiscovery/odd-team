## What

On a data-quality test's detail page, the **Test report -> History preview** fetches only the most recent **10** runs and renders them with no indication that more exist. When a test has accumulated more than 10 runs, the older ones are silently truncated from the preview and the operator gets no "+N more" badge, total count, or "see all" cue. Discoverability of the full History tab depends entirely on the operator already knowing it is there - there is no signal in the preview that it is showing a clipped list.

## Where

`odd-platform-ui/src/components/DataEntityDetails/TestReport/TestReportDetails/TestReportDetailsHistory/TestReportDetailsHistory.tsx:30-32` - the page size is hardcoded to `10` and nothing downstream surfaces the total:

```tsx
React.useEffect(() => {
  dispatch(fetchDataEntityRuns({ dataEntityId: dataQATestId, page: 1, size: 10 }));
}, [fetchDataEntityRuns, dataQATestId]);
```

The render path (same file, lines 33-68) simply maps `dataQATestRunsList` - i.e. whatever the page-1/size-10 fetch returned - into rows, with no count, no "+N more", and no link to the full history. There is no use of a total/`hasNext` field to drive a cue.

## Why it matters

Silent, not loud: a test with 50 runs looks identical to a test with exactly 10. An operator triaging a flapping data-quality check sees the 10 most recent results and may reasonably conclude that is the complete run history for the test, missing older failures or a pattern that only emerges over a longer window. The defect is purely a discoverability/UX gap - no data is lost server-side, the History tab still works - which is why this is medium rather than high. But "the preview looks complete when it is not" is exactly the kind of quiet wrong-impression that erodes trust in the quality dashboard.

## Suggested fix

Drive a count cue from the runs total. Concretely:
- Surface the total run count (the runs list endpoint is already paged, so a total/`pageInfo` is available) and render a "+N more" badge or a "See all N runs" link beside the preview header that deep-links to the full History tab.
- Alternatively, render an explicit "Showing latest 10 of N" caption.

Open to alternatives on the exact affordance - the load-bearing requirement is that the preview must visibly signal when it is clipped.
