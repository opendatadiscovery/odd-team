## Description

**Pilot of the ADR pillar** (establish-the-process pass). Promotes the strongest implicit-ADR candidate — `ADR-CANDIDATE-001`, the contract-first controller pattern (18-sidecar support, wisdom-test PASS) — into the first published Architecture Decision Record under the docs site's Developer Guides → Architectural Decision Log, and wires it into the ontology (`ImplicitADR` → `PROMOTED_TO` → `ADR`).

The decision: every REST controller in `odd-platform-api` is a thin delegate that `implements` an OpenAPI-generated `*Api` interface; HTTP method/path annotations live on the generated interface (compiled from `openapi.yaml`), never on the controller. Adding a route is a spec-edit-and-regenerate flow. The lone hand-coded exception is `AlertManagerController`.
