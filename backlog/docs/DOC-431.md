## Description

1. **Great Expectations** (`## Great Expectations`, line 13) — push-client via `odd-great-expectations`.
2. **dbt tests** (`## dbt tests`, line 17) — push-client via `odd-dbt`.
3. **Statistical profiles via `odd-collector-profiler`** (`## Statistical profiles via odd-collector-profiler`, line 21) — pull-strategy collector.
4. **Custom frameworks** (`## Custom frameworks`, line 25) — this is the escape hatch (`POST /ingestion/entities`), not a fourth canonical path. The "plus a custom-framework escape hatch" clause already accounts for it.
