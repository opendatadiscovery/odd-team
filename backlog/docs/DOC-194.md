## Description

`POST /ingestion/entities/datasets/stats` (the dataset-field statistics ingestion endpoint) is named in the existing live `enable-security/README.md` as **outside the ingestion filter's coverage** (per DOC-GAP-239 corroboration). The endpoint is unauthenticated under EVERY supported configuration. What no doc page captures is **the write shape** — and the write shape is a data-integrity violation that operators can be misled into thinking is safe.

**Facet 1 — Cross-dataset write surface (F-095a, CRITICAL).** `DatasetFieldServiceImpl.updateStatistics` (line 158-181) resolves writes BY FIELD ODDRN ONLY — `getLastVersionDatasetFieldsByOddrns(statistics.keySet())` queries the field-table by ODDRN with no JOIN to the declared parent's dataset_id. The endpoint accepts a payload `{ items: [{ datasetOddrn: A, fields: { <oddrn-of-field-in-dataset-B>: stat } }] }` and writes the `stat` JSONB to dataset B's field rows while triggering FTS recompute on dataset A (the declared parent). Result: any caller knowing a field's ODDRN can poison any dataset's field statistics through any other dataset's parent declaration. Downstream consumers (Quality Dashboard rings F-022/F-032, Dataset Structure tab, BI tools reading `dataset_field.stats`) render attacker-controlled values without indicator. Combined with the endpoint being unauthenticated under every supported configuration, this is a **trivial data-integrity attack on any dataset's field statistics**.

**Facet 2 — Replay-with-fewer-tags silently destroys EXTERNAL_STATISTICS-origin tags (F-095b, HIGH).** `DatasetFieldServiceImpl.updateFieldsTags` (line 217-227) calls `reactiveTagRepository.deleteDatasetFieldRelations(relationsToDelete)` for tags absent from the new payload, where `relationsToDelete` = the set of existing EXTERNAL_STATISTICS-origin relations not in the new set. A re-POST with FEWER tags silently removes the absent tags. Same destructive-replace shape as F-008's batch-replace contract but applied to per-field tags. No `replace_tags: bool` flag, no merge-semantics opt-in.
