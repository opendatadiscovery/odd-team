## Description

Live `/user-owner-association` is silent on the consequences of an unbind. The ConfirmationDialog actionText is "User X will stop being associated with owner Y" — locally true but globally under-explained.

Code reality (per sidecar references + F-064 silent-empty pattern): an unbind causes (a) the user's "My objects" Activity view to go silent-empty; (b) the user's Alerts "My" view to go silent-empty; (c) the user loses ownership-scoped permissions granted through that Owner's Role bundles (F-006, F-011). The dialog text describes only the local effect.

Operator-visible consequence: an admin clicks Remove and the user's downstream views go silent. The user reports "my dashboards are empty" without knowing the unbind caused it; the admin has no doc to point at to explain.
