## Description

The published Entity detail page (created by DOC-263) documents the Overview sidebar truncation defects
as **caveats** in Section 5. The odd-platform #1768 fix (CTRIB-026, milestone 0.29.0) **resolves** them,
so the section becomes incorrect for 0.29.0+ once that release ships:

- **Defect 1 (warning) — "Tags ordering is not importance-stable across the truncation cap."** FIXED:
  the Tags panel now sorts the whole set by importance, then slices, so important tags appear in the
  visible top-20 (and `View All` continues the same single ordering). The same fix applies to the
  term-detail tag list and the dataset-field tag list.
- **Defect 2 (warning) — "Groups and Terms visible-window ordering is undefined" (the no-op `.sort()`).**
  RESOLVED: the misleading no-op sort is removed; those panels render in the order the platform returns
  them (no importance signal). The "do not rely on alphabetical" guidance is kept (now stated as plain
  behaviour, not a stringification defect).
- **Defect 3 (info) — truncation visible only via the `View All (N)` count.** RESOLVED: an inline
  `Showing 20 of N` hint now shows above a truncated panel.

The change rides the **`release/0.29.0`** documentation train and publishes at the 0.29.0 release gate
(the live manual describes the latest published release — `adrs/drafts/release-train-doc-gating.md`).
