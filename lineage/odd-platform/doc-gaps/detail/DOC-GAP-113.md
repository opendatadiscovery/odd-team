    1. **Doc-side primary** (the immediate gap): add a "Payload contract: replace-not-merge" admonition to `/developer-guides/api-reference` (or a new "Ingestion semantics" sub-page on `/integrations/`): "**The `POST /ingestion/entities` payload represents the complete state of each entity's metadata, lineage, dataset versions, group memberships, and ERD relationships from the calling datasource.** Fields omitted from a re-ingestion are DELETED, not preserved. Collectors MUST either (a) emit complete state every call, or (b) skip the partial entity entirely (don't include it in the payload).
