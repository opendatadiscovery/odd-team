Production deployments should ensure (a) the platform's `Exception` handlers do NOT include stack-trace fragments in the response body (the catch-all returns `'Internal Server Error'` today, which is correct); (b) reverse-proxy configurations strip internal-path information from the URL surface where appropriate. Defence-in-depth; not a critical surface today but a regression hazard."
