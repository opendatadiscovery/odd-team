## Description

Author the top-down backbone **umbrella** ADR: **PostgreSQL is the only required runtime
dependency**. ODD needs no message broker, ZooKeeper/Consul, or external search engine — queuing,
cross-replica leader election, notifications, lineage traversal, and full-text search are each
built on a Postgres feature. The umbrella names the deployment posture that the already-published
tactical ADRs (0020 queue, 0043 WAL, 0028 partitioning, 0044 lazy-create) are individual instances
of; it cross-links them rather than superseding them (maintainer: do not churn live URLs).

absorbing ADR-CANDIDATE-020/043/044/028/057/052. Passes the wisdom filter: it generates a pattern

constrains future work (a feature that "needs a broker" works against the platform's defining
posture).
