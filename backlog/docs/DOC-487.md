## Description

`multilingual-ui.md` described two i18n build checks and the natural-keys pattern as universal.
CTRIB-036 / odd-platform#1776 corrected a distinct defect class — wrong VALUES, not missing keys:
all six non-English catalogs had translated the one **symbolic** key `main search placeholder`
(whose English value is the home-page search hint) by the key's words rather than its meaning, and a
third build check (the symbolic-key value guard, `odd-platform-ui` `i18n-key-parity.test.ts`) now
guards that class.

The page edit landed on the **`release/0.29.0`** train (`documentation@a0f4656`) — it describes
unreleased behaviour, so it publishes at the 0.29.0 release gate, not on docs `main`.
