## Description

`multilingual-ui.md` "How to contribute a new locale" closes with: *"The build-and-run workflow for testing a locale change locally is documented at [Build and run ODD Collectors](developer-guides/build-and-run/build-and-run-odd-collectors.md) (the same dev-server bootstrap applies to UI work)."*

The link target is `developer-guides/build-and-run/build-and-run-odd-collectors.md` — the Collectors dev-loop doc, which has nothing to do with running the UI dev server to verify a UI locale change. The parenthetical "(the same dev-server bootstrap applies to UI work)" claim is also wrong — Collector dev is Python/Poetry, UI dev is Vite + Node.

The correct target depends on what exists in `developer-guides/build-and-run/`:
- If there is a `build-and-run-odd-platform-ui.md` (or similar), link that instead.
- If there is no UI dev-server doc, drop the sentence entirely.
