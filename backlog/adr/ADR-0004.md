## Description

Promote `ADR-CANDIDATE-004` into a published ADR. The decision: the GenAI feature ships
**disabled-by-default** — `enabled: false` is explicit in `application.yml` — and when an
operator enables it, the defaults are deliberately minimal so the operator must configure
the integration explicitly rather than inheriting a working-but-unsafe configuration. The
decision is part of the platform's ship-disabled-by-default feature-gating family
(alongside Data Collaboration `-019`, Notifications `-040`).
