## Description

The platform change for odd-platform#1756 (CTRIB-016) ships at **0.28.0**: `JooqFTSHelper.tsQuery` strips the
full tsquery operator set before building the `to_tsquery(...)` argument, so a metacharacter in the search box
(`( ) : & | ! '`, or `<`) no longer raises Postgres `42601` -> HTTP 500, and no longer persists a poisoned
`search_facets` session row that 500s on every later read. The fix is at the single shared FTS sink, so it covers
both the catalog (`/search`) and the Dictionary/term (`/termsearch`) surfaces.

`docs/data-discovery/search.md` carried a **`warning`** caveat (added by DOC-260) telling operators to *"Avoid the
characters `( ) & | ! * :` in the search box"* because they 500'd the session. That caveat is now stale. It is
replaced with an **`info`** note describing the actual post-fix behaviour: the operators are treated as word
separators (so `user(id)` searches `user` and `id` and still matches an entity named `user(id)`), an all-operator
query returns **No matches found**, the same handling applies to the Dictionary search box, and the pre-0.28.0 500
is kept as a historical parenthetical (house style, matching the sibling "as of 0.28.0; earlier releases …" notes
on the same page).
