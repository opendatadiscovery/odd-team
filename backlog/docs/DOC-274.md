## Description

`docs/developer-guides/build-and-run/README.md` is a 13-line section landing page that lists only two children in its "Contents" enumeration:

```
* [Build and run ODD Platform](build-and-run-odd-platform.md) — backend (Java + Gradle + Spring WebFlux + jOOQ + Flyway) and frontend (TypeScript + React); how to run the platform from source for development.
* [Build and run ODD Collectors](build-and-run-odd-collectors.md) — Python collectors bundled in the `odd-collectors` monorepo (`odd-collector`, `-aws`, `-gcp`, `-azure`) plus the standalone `odd-collector-profiler`; how to set up a Python environment, install per-collector dependencies, and run a collector locally.
```

A third sibling file exists in the same directory — `custom-collectors.md`, 465 lines, "Build a custom collector" — and is cross-referenced from `main-concepts.md`, `Architecture.md`, `SUMMARY.md` (line 121), and `integrations/README.md`. It is a load-bearing developer guide for the contributor flow ("when an existing adapter doesn't fit"), but is **invisible** to a reader who navigates to the section README first.

The README's introductory prose is also misleading: *"This section shows how to build and run code for each part of ODD infrastructure — ODD Platform backend and frontend, and the ODD Collectors family."* The "custom adapter authoring" path is omitted entirely. A reader following the [How to contribute](../how-to-contribute.md) flow ("take a look at the [Build and run](build-and-run/README.md) page on how to set up your environment and run your code") lands on this README and gets a half-map.
