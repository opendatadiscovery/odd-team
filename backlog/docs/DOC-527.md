## Description

ST-9 (#1843) ships the first numeric-range facet on the unified catalog search — a **Popularity** range over each
data entity's snapshotted view count — plus the **Most popular** sort option and a **View all** link on the home
page's Popular tile. All of it is unreleased 1.0.0 behaviour, so the manual's description of it lives on the
`release/1.0.0` train and publishes at the release gate, never on docs `main`.

The section was AUTHORED in the CTRIB-066 run (not merely tracked): `documentation@docs/CTRIB-066-popularity-facet`
carries the four page edits listed above; the draft PR against `release/1.0.0` is opened at the CTRIB-066 draft-PR
step and its URL is recorded in `contributor/CTRIB-066.md`.
