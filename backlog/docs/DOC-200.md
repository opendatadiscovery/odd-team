## Description

The alerting page names the `GET /api/dataentities/{data_entity_id}/alerts` workaround for exporting alert audit data before manual resolution (live page: "export the alert audit data before manually resolving — returns the open and recently-resolved set"). But the workaround text is **silent on three completeness concerns** that materially change operator behaviour, and the page is **silent on the listing UX constraints** of the per-entity Alerts tab and the global Alerts list page.

**Workaround completeness caveats (F-014a — strengthens DOC-GAP-157).**

- **Pagination shape**: `page` and `size` query params are required; small sizes silently truncate a long export. No `@Min`/`@Max` on the controller; OpenAPI `PageParam`/`SizeParam` declare no `minimum:`/`maximum:`. Operators following the workaround at default size lose audit history.
- **Soft-delete-inclusive read**: `existsIncludingSoftDeleted` (AlertServiceImpl.java:327-335) gates the read inclusive of soft-deleted entities. A dataEntityId that is soft-deleted (hidden from catalog list endpoints) still returns alert history here — same data-shape leak the F-014 finding family surfaces.
- **Cross-owner posture** beyond what DOC-GAP-157 names: the repository query (ReactiveAlertRepositoryImpl.java:182-199) has NO `OWNERSHIP` join; contrast `listByOwner` at 160-178 which DOES. Operators reading the URL namespace (`/api/dataentities/{id}/alerts`) naturally assume per-owner scoping; this is wrong.

**Listing constraints framing (F-014c + F-126c framing + F-126d framing).**

- **Per-entity Alerts tab**: hardcoded `size=30`; no filter UI; no status selector; no export affordance. Documenting this as "alert history viewer — for bulk operations or filtered queries, use the API workaround above" closes the doc gap until UI hardening lands (PLT-031).
- **Global Alerts list page**: no filter UI (no status / type / date / entity-name search), no bulk-resolve, no export. Documenting these as known constraints today + cross-linking to the workaround API is the right interim doc.
