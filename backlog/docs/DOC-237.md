## Description

There are SIX distinct admin-promotion shapes across the four authentication modes, plus a seventh form-login-only role-binding-at-creation flow. Each provider has its own page documenting its own knobs in isolation; **no unified landing page exists for operators evaluating which mode best fits their identity provider, OR operators migrating between modes**. F-124d names the gap explicitly.

**The six shapes:**

| # | Provider / mode | Admin-detection knob | Match semantic | Silent caveat |
|---|---|---|---|---|
| 1 | LDAP | `auth.ldap.groups.admin-groups` | case-insensitive **SUBSTRING** | Overpromotes if token is short. If `groups` unset, silent USER-only path. |
| 2 | AWS Cognito | `auth.oauth2.client.{id}.admin-groups` | exact-match against Cognito groups claim | — |
| 3 | GitHub | `admin-groups` (team slug) + `admin-principals` (login) | SUBSTRING (groups) + exact (principals); **admin-principals BYPASSES org-gate** | Hard-coded `api.github.com` (no GHES) |
| 4 | Google | `admin-principals` (email) + `admin-attribute` (custom claim) | exact-match | `admin-groups` field BINDS but is **SILENT NO-OP** |
| 5 | Azure AD | `admin-groups` (roles or groups claim) | exact-match | — |
| 6 | ODD_IAM | `userinfo` flag from IAM | flag-based | — |
| (7) | LOGIN_FORM | (none — role-binding-at-creation via Management UI) | — | Every authenticated user is granted ADMIN; SECURITY_RULES table is INERT (DOC-234). |
| — | Okta, Keycloak | (none — fall through Custom OIDC) | — | **No admin path** beyond manual Owner-Role binding. |
| — | DISABLED | (none — synthetic admin) | — | Anonymous unauthenticated caller of `/api/identity/whoami` IS admin with ALL permissions (DOC-239). |

The fragmentation across pages is itself the gap. An operator migrating from LDAP to GitHub OAuth needs to know both that the substring-match semantic carries over AND that `admin-principals` is an additional bypass that LDAP doesn't have. An operator evaluating "which provider should we use for SOC2-friendly admin precision?" needs the matrix.
