To safely rename or delete a referenced term, you must first either: (i) edit every description that mentions it to remove or update the `[[ns:term]]` syntax; (ii) soft-delete the parent entities whose descriptions reference the term (the guard ignores soft-deleted parents — see also DOC-GAP-118 ingestion restore-on-re-ingestion behaviour)."
