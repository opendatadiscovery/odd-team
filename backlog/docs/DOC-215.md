## Description

Live `/user-owner-association` is silent on the DECLINED branch UX altogether. Code reality (sidecar reference `OwnerAssociation.tsx:28,61-82`): when `status=DECLINED`, the rejection message renders above a fresh form with an X-dismiss button backed by `useState(true)` (component-local state, no persistence). Refreshing the page re-renders the notice. No per-decline-reason surface; the message is a generic translation string. No escape path other than re-requesting with a different name (which itself starts the cycle again).

Operator-visible consequence: a user who saw a DECLINED message and dismissed it cannot remember the act between sessions; the banner reappears on every login until their next submitted request changes the status. Also: no operator-visible audit of why they were declined.
