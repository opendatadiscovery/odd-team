## Description

Running the full FE unit suite (`odd-platform-ui` → `pnpm test` / `vitest run`) is **RED** on `origin/main`
(`fd71eb3d`) with **one** failing test — unrelated to #1766, pre-existing, surfaced while running the

Playwright run are both commented out), so it only bites locally — but the FE test suite should be green.

**Failing test:** `src/locales/__tests__/i18n-key-parity.test.ts` →
*"i18n no unwrapped object-property label literal (#1751 / PLT-205 wave 3) > every user-facing tab/menu/status
label uses t(...), never a raw object-property string"*.

**Offender reported:** `components/Terms/TermDetails/TermLinkedTermsList/LinkedTermsList.tsx:63  message: 'Unknown Error'`.

## Root cause — a guard false-positive, not a real unwrapped label

`LinkedTermsList.tsx:63` is a **ternary**, not an object-property label:

```tsx
message: error instanceof Error ? error.message : 'Unknown Error',
```

The guard's detector `OBJ_PROP_LITERAL = /\b(name|label|title|...|message|...)\s*:\s*'([^'{}]*)'/g`
(`i18n-key-parity.test.ts:189`) is meant to catch object-property labels like `{ name: 'My Objects' }`. But
`\bmessage\s*:\s*'...'` also matches the substring `error.message : 'Unknown Error'` — the ternary's `else`
branch — treating the ternary `:` as a property colon. So it flags `'Unknown Error'` as an unwrapped label
when it is the `message` field's *fallback value* in an internal `AppError`-shape object, not a UI label.

Introduced by #1798 (CTRIB-028, the Term Detail hardening) which added `LinkedTermsList.tsx`; the guard itself
shipped in #1751 / PLT-205.

## Suggested fix (guard, not the code)

Tighten `OBJ_PROP_LITERAL` so a property only matches at an **object-literal position** — preceded by `{`, `,`,
or start-of-line + whitespace — so a `<expr>.<prop> :` ternary no longer matches. (Alternatively, but less
correct: wrap the two `'Unknown Error'` fallbacks in `t()` — they are error-object fallbacks, not labels, so
the guard fix is the right one. Note `getErrorResponse` similarly returns a bare `'An error occurred'` fallback
that is intentionally un-keyed.)
